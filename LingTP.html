点击选择文件 或将文件拖到此处 支持 .json（LingTP / 通用 nodes-links）、.csv / .txt（LLDP 邻居表、连接表）

1. CSV / LLDP 连接表（最常用）

表头可用中文或英文，程序自动识别列：

本端设备,本端接口,对端设备,对端接口,本端类型,对端类型,带宽
CORE-SW1,GE0/0/1,ACC-SW1,GE0/0/24,switch,switch,1G
FW-01,GE1/0/1,CORE-SW1,GE0/0/23,firewall,switch,10G

可识别的列名：本端设备/local_device/hostname/local、本端接口/local_port/local_interface、 对端设备/remote_device/neighbor/peer、对端接口/remote_port/peer_interface、 类型/type、IP/管理IP、带宽/bandwidth/speed。
无表头时按「本端设备,本端接口,对端设备,对端接口」顺序解析。

2. LingTP JSON

本工具导出的 .json，含坐标、接口、链路，完整还原。

3. 通用 JSON

{"nodes":[{"id":"sw1","name":"CORE-SW1","type":"switch","ip":"10.0.0.1"}],
 "links":[{"source":"sw1","target":"sw2","sourcePort":"GE0/0/1","targetPort":"GE0/0/2"}]}

导入后若无坐标，将自动执行分层布局。
